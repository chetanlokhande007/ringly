# Ringly Chrome Extension

## Install (development)

1. Unzip `ringly-extension.zip`
2. Before installing, open `popup.html` and replace `__APP_URL__` on line 11 with your deployed Ringly URL (e.g. `https://your-project.lovable.app`)
3. Open `chrome://extensions`
4. Enable **Developer mode** (top right)
5. Click **Load unpacked** and select the unzipped folder

Works in Chrome, Edge, Brave, Arc, and Opera.
